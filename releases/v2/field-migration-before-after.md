# Record Health Check — Field Migration (Before → After)

Every field on both custom metadata types: current shipped state on the left, proposed state on the right. The **After** description and help text are authored fresh for the new field names, labels, and picklist values, and are written to be self-sufficient — everything needed to configure the field correctly is stated inline, with no reliance on outside docs. Other fields are referenced by their **new label**. This file is the authoritative deployed 51-field contract; broader V2 architecture and decision rationale live in [`V2-RELEASE-PLAN.md`](V2-RELEASE-PLAN.md).

> **Salesforce metadata clarification:** In this document, `Long Text (255)` means a
> 255-character text field. Salesforce Metadata API requires `LongTextArea` fields to
> have a minimum length of 256, so `CheckDescription__c` and `CardSubtitle__c` deploy as
> `Text(255)`. Unbounded entries shown as `Long Text` remain `LongTextArea(32768)`.
